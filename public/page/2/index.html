About
Aug 1, 2023 One minute

heyo is a responsive, minimalist, and pretty theme built for hugo, based on Alexander Bilz’s Anatole.

Features

  • Dark theme
  • Cover images
  • Pretty visualizations in the sidebar
  • Table of Contents in the sidebar
  • Callout shortcode
  • Badges shortcode
  • Support for custom CSS and JS
  • Multilingual support (english and brazilian portuguese, for now)
  • Open Graph support

Quickstart

To try the exampleSite you just need to:

git clone https://github.com/LucasVadilho/heyo-hugo-theme heyo
cd heyo/exampleSite && hugo server --themesDir ../..

Live preview

You can check a live preview at heyo-theme.oioipio.com. Also, scan the QR code if you want to preview on mobile!

Sobre
Aug 1, 2023 One minute

heyo é um tema responsivo, minimalista e bonito para hugo. Ele foi baseado no Anatole de Alexander Bilz.

Features

  • Imagens de capa
  • Visualizações in the sidebar
  • Índices in the sidebar
  • Callout shortcode
  • Badges shortcode
  • Tema escuro
  • Suporte para CSS e JS customizados
  • Suporte para Multilinguas (inglês e pt-br, por enquanto)
  • Open Graph support

Quickstart

Para testar o exampleSite é só:

git clone https://github.com/LucasVadilho/heyo-hugo-theme heyo
cd heyo/exampleSite && hugo server --themesDir ../..
